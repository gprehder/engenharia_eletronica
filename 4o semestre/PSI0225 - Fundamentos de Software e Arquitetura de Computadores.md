**14. Conteúdo Programático:**
* [texto em português]: 
1. Estruturas básicas de software: sequências, laços, condicionais.
2. Complexidade de algoritmos: linear, quadrática, exponencial.
3. Programação orientada a objetos: classe, instância, herança, ligação dinâmica, exceções.
4. Estruturas de dados: lista ligada, pilha, fila, mapas.
5. Bibliotecas e APIs.
6. Noções de arquitetura de computadores: modelo de Von Neumann, instrução, programa, memória, processador, entrada/saída.
7. Noções de arquitetura de software: frameworks, modelo cliente-servidor, nuvem, front-end, back-end. 

* [texto em inglês]: 
1. Basic software structures: sequences, loops, conditionals.
2. Complexity of algorithms: linear, quadratic, exponential.
3. Object-oriented programming: class, instance, inheritance, dynamic binding, exceptions.
4. Data structures: linked list, stack, queue, maps.
5. Libraries and APIs.
6. Notions of computer architecture: Von Neumann model, instruction, program, memory, processor, input/output.
7. Understanding software architecture: frameworks, client-server model, cloud, front-end, back-end.

**16. Método de avaliação :**
* [texto em português]: A avaliação dos estudantes será processual e multifacetada, distribuída entre a validação de competências lógicas, conceituais e de engenharia de software. A nota final será composta por avaliações teóricas individuais, focadas na análise de complexidade de algoritmos, conceitos de orientação a objetos e fundamentos de arquitetura de computadores, e por atividades laboratoriais práticas. Estas atividades práticas incluirão desafios periódicos de codificação para implementação de estruturas de dados e lógica de programação, culminando no desenvolvimento de um projeto de software integrado. Neste projeto, os alunos deverão aplicar os conceitos de programação orientada a objetos, bibliotecas e arquitetura cliente-servidor para construir e documentar uma aplicação funcional.

* [texto em inglês]: Student assessment will be formative and multifaceted, balanced between validating logical, conceptual, and software engineering competencies. The final grade will be based on individual theoretical exams, focusing on algorithm complexity analysis, object-oriented concepts, and computer architecture fundamentals, alongside practical laboratory assignments. These practical activities will include periodic coding challenges to implement data structures and programming logic, culminating in the development of an integrated software project. In this project, students must apply object-oriented programming concepts, libraries, and client-server architecture to build and document a functional application.

---

**17. Critério de avaliação:**
* [texto em português]: Os critérios de avaliação contemplam a capacidade de abstração lógica e a eficiência no desenvolvimento de software, com foco no uso correto de estruturas de controle, orientação a objetos e estruturas de dados apropriadas para cada problema. Será avaliado o rigor conceitual na análise de complexidade de algoritmos e na compreensão dos fundamentos de arquitetura de computadores e de software. Adicionalmente, serão considerados a qualidade técnica do código (organização, legibilidade e boas práticas), a integração assertiva de bibliotecas e APIs, e a capacidade de projetar e documentar uma aplicação funcional baseada no modelo cliente-servidor.
  
* [texto em inglês]: The assessment criteria encompass logical abstraction capacity and software development efficiency, focusing on the correct utilization of control structures, object-oriented programming, and appropriate data structures for each problem. Conceptual rigor will be evaluated regarding algorithm complexity analysis and the understanding of computer and software architecture fundamentals. Additionally, the criteria include code quality (organization, readability, and best practices), the effective integration of libraries and APIs, and the ability to design and document a functional application based on the client-server model.

---

**18. Normas de recuperação:**
* [texto em português]: A recuperação será focada nos tópicos de maior dificuldade identificados durante o semestre. O aluno deverá realizar estudos dirigidos e exercícios complementares sobre os conteúdos específicos não atingidos, seguidos de uma nova avaliação para verificar a superação das deficiências.
* [texto em inglês]: Remedial work will focus on the topics of greatest difficulty identified during the semester. Students must complete guided studies and complementary exercises on the specific contents that were not mastered, followed by a new assessment to verify the resolution of learning gaps.
